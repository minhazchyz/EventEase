# EventEase – Event Management Application

## Project Overview
EventEase is an Android-based event management application developed as a third-year academic project. The main goal of this project is to make event-related activities easier and more convenient for users.

## Objectives
- To provide a convenient platform for event management.
- To simplify event-related activities.
- To implement user authentication and verification.
- To improve the overall user experience.

## Features
- User Registration and Login
- OTP-Based User Verification
- User-Friendly Interface
- Event Management Features

- Programming Language: Java
- Development Environment: Android Studio

## Installation and Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/minhazchyz/EventEase.git
   ```
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Configure the required database and dependencies.
5. Run the application on an Android emulator or physical device.
